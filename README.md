# Hamster Vet

Projeto web construído com Next.js e React para explorar uma experiência moderna de site institucional na área veterinária.

A aplicação está organizada em seções de apresentação, serviços, informações institucionais, equipe e contato.

## Stack verificado

* Next.js 16
* React 19
* TypeScript
* Tailwind CSS
* Base UI
* Lucide React
* Vercel Analytics
* shadcn
* pnpm

## Estrutura da página

A página principal é composta por:

* Hero
* Serviços
* Sobre
* Equipe
* Contato
* Header
* Footer

O projeto também possui um loader de entrada e componentes separados por responsabilidade.

## Desenvolvimento

Instale as dependências:

```bash
pnpm install
```

Execute o ambiente local:

```bash
pnpm dev
```

Gere o build:

```bash
pnpm build
```

## Origem

O projeto foi iniciado com v0 e segue sendo mantido como um projeto Next.js convencional no repositório.
